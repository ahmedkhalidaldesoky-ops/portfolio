📊 Turning data into decisions — AdventureWorks Sales Dashboard

I recently built an interactive Power BI dashboard to analyze sales performance for AdventureWorks between 2020 and 2022.

🔍 Key highlights:
• $25M total revenue with $10M profit
• 25K+ orders with a low 2.2% return rate
• Clear category performance breakdown (Accessories leading in orders)

💡 Insights that stood out:
• Revenue is growing steadily, with a +3.3% increase in the latest month
• Orders slightly declined, while returns decreased — a positive operational signal
• Customer base is expanding, but revenue per customer is decreasing
→ This suggests an opportunity to improve upselling and cross-selling strategies

🌍 The dashboard also provides:
• Geographic performance across multiple regions
• Product-level deep dive with profit and return analysis
• Customer segmentation by income and occupation
• Interactive features like drill-through and price simulation

📱 I also designed a dedicated mobile view to ensure accessibility and usability on smaller screens, allowing stakeholders to track performance insights on the go.

This project helped me focus not just on building visuals, but on extracting meaningful business insights from data.
